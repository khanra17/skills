## What it does

`i-have-adhd` changes how the agent presents answers for the rest of the session. It makes next steps clear, groups information so it is easier to scan, and gives brief progress reminders when they help.

It follows your stated preferences rather than making assumptions about your abilities. It changes presentation without reducing the investigation, skipping required information, or replacing your decisions.

## When to reach for it

Type `/i-have-adhd` when you want help following a task across several exchanges without losing your place.

For example, while organizing recurring payments, the agent can say:

> The recurring payments are listed. Next, mark the ones you no longer use.

It does not repeat that status during every follow-up question. After an interruption, it can remind you where you stopped.

Use [wait-what](./wait-what.md) to re-explain one confusing answer. Use [unslop](./unslop.md) to edit a piece of writing rather than change how the session is guided.

## Common questions

**How long does it stay active?**

For the current session, including topic changes. Say "stop adhd mode", "normal mode", or otherwise ask to turn it off. It does not write permanent project preferences unless you ask.

**Does every answer become a short action list?**

No. Tasks get clear steps, conceptual questions get explanations, and requests for options get options with trade-offs. You can still ask for a detailed walkthrough.

**Will it hide relevant details to keep the answer short?**

No. It groups and prioritizes information without dropping items needed to answer the request. Warnings, uncertainty, and approval requirements remain visible.

**Does it always estimate how long something takes?**

No. It gives an estimate only when there is a reasonable basis and the estimate helps. Otherwise it describes what the next step involves rather than inventing a duration.

**Will it change the style of a document I ask it to write?**

The requested document keeps its intended form. For example, a letter should not become a numbered task list because this mode is active.

## It's working if

- You can find the next action when there is one to take.
- Ordered work has clear, manageable steps.
- Progress reminders help you resume without repeating the same status every turn.
- Explanations remain complete, including uncertainty and relevant trade-offs.
- Turning the mode off ends these session-wide preferences.
